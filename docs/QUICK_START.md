# ⚡ QUICK START ADMIN DASHBOARD

> Catatan struktur terbaru: `admin.css` berada di `assets/css/admin.css` dan `admin.js` berada di `assets/js/admin.js`.

**5 Minutes to Get Started!**

---

## 🚀 Step 1: Open Admin Dashboard

### Desktop
1. Navigate to folder: `/WEB EDU/admin/`
2. Double-click: `admin.html`
3. Browser will open automatically

### Mobile/Tablet
1. Share file via network or device
2. Open in mobile browser
3. Dashboard automatically responsive!

## 📚 Step 3: Add First Modul

### 3A. Click "Kelola Modul" Menu
- Left sidebar → "Kelola Modul"
- Page changes to modul management

### 3B. Click "Tambah Modul" Button
```
Yellow/Blue button di top-right
```

### 3C. Fill Form
```
Nama Modul:      "Penjumlahan & Pengurangan"
Mata Pelajaran:  "Matematika"
Deskripsi:       "Belajar penjumlahan dasar"
Modul Aktif:     ✓ (checked)
```

### 3D. Click "Simpan Modul"
✅ Success! Modul added to database

### 3E. See in Table
Table akan update otomatis menampilkan modul baru

---

## 📋 Step 4: Add First Tugas

### 4A. Click "Kelola Tugas" Menu
- Left sidebar → "Kelola Tugas"

### 4B. Click "Tambah Tugas" Button

### 4C. Fill Form
```
Judul Tugas:     "Quiz Penjumlahan"
Modul:           "Penjumlahan & Pengurangan"
Deadline:        "2024-07-20"
Nilai Maksimal:  "100"
Deskripsi:       "Quiz online 10 soal"
Tugas Aktif:     ✓
```

### 4D. Click "Simpan Tugas"
✅ Success! Tugas added

## 👥 Step 5: Add First Siswa

### 5A. Click "Data Siswa" Menu

### 5B. Click "Tambah Siswa" Button

### 5D. Click "Simpan Siswa"
✅ Success! Student added

## 🔍 Step 6: Try Search & Filter

### Search Modul
```
Modul page → Search input
Type: "Penjumlahan"
→ Results filter instantly!
```

### Filter by Subject
```
Mata Pelajaran dropdown
Select: "Matematika"
→ Show only Matematika moduls
```

### Search Siswa
```
Siswa page → Search input
Type: "Adi"
→ Show Adi's info
```

---

## ✏️ Step 7: Edit Data

### Edit Modul
```
1. Go to "Kelola Modul"
2. Find modul in table
3. Click "Edit" button
4. Change fields
5. Click "Simpan Modul"
```

### Edit Tugas/Siswa
Same process as modul

---

## 🗑️ Step 8: Delete Data

### Delete Modul
```
1. Find modul in table
2. Click "Hapus" button
3. Confirm: "Apakah yakin?"
4. Click "OK"
5. Modul deleted!
```

---

## 📊 Step 9: Check Laporan

### 9A. Click "Laporan" Menu

### 9B. View Tabs
```
Tab 1: Laporan Nilai
       → Nilai siswa per modul

Tab 2: Kehadiran
       → Data hadir/alpa/sakit/izin

Tab 3: Progress Pembelajaran
       → Visual progress per siswa
```

---

## ⚙️ Step 10: Backup Data

### 10A. Click "Pengaturan" Menu

### 10B. Go to "Backup & Export"

### 10C. Click "Export Semua Data"
```
File akan di-download:
Nama: edusky-backup-2024-07-14.json
Berisi: modul, tugas, siswa data
```

### 10D. Save File
Save di tempat aman untuk backup!

## 🆘 Quick Troubleshooting

### Q: Data tidak simpan
**A:** Refresh browser, clear cache, try again

### Q: Sidebar hilang di mobile
**A:** Click hamburger icon (☰) di top-left

### Q: Form tidak bisa kirim
**A:** Check all required fields (dengan *)

### Q: Search tidak bekerja
**A:** Pastikan text yang diketik match dengan data

### Q: Export error
**A:** Check browser console, gunakan Chrome
